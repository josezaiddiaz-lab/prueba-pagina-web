# 🎲 Simulador de Dado Virtual Online

Aplicación web gratuita e interactiva desarrollada en Python con Streamlit para lanzar un dado virtual de 6 caras en línea de forma rápida y aleatoria.

👉 **[Probar el Simulador de Dado Online aquí](https://streamlit.app)**

## ✨ Características
* **Lanzamiento instantáneo:** Genera resultados aleatorios del 1 al 6 con un solo clic.
* **Sin instalaciones:** Funciona directamente desde el navegador en computadora o celular.
* **Ideal para juegos de mesa:** Útil cuando necesitas un dado rápido en línea.
